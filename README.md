# 📚 Learning Management System (LMS) - Microservices Architecture berbasis GraphQL

   Aplikasi web Learning Management System (LMS) Adaptif yang dikembangkan menggunakan pendekatan arsitektur Microservices berbasis GraphQL untuk meningkatkan skalabilitas, modularitas, dan efisiensi komunikasi data. Sistem ini mengintegrasikan algoritma adaptif berbasis evaluasi hibrida melalui soal pilihan ganda dan esai untuk menyesuaikan jalur pembelajaran berdasarkan capaian kompetensi mahasiswa, dengan menyediakan materi pengayaan bagi mahasiswa yang memenuhi kriteria serta materi remedial bagi mahasiswa yang memerlukan penguatan pemahaman.
